# MyFLicks

MyFLicks is a Flask-based web application that allows users to create and manage personal movie watchlists. Users can explore movie details fetched from the TMDB API and add movies to their lists.

## Features

- **Personal Movie Watchlists:** Create, view, and manage custom movie lists.
- **TMDB API Integration:** Search for movies and view detailed information fetched from the TMDB API.
- **User Authentication:** Sign up, log in, and manage your profile.
- **Supabase Database:** The database is managed using SQLAlchemy and hosted on Supabase.

## Technologies Used

- **Python 3.8.13:** The application is built using Python.
- **Flask:** A lightweight web framework for building web applications.
- **SQLAlchemy:** ORM used for database interactions.
- **Supabase:** Hosting the PostgreSQL database.
- **TMDB API:** Fetching movie details.
- **Render:** Live deployment at [https://myflicks-flask.onrender.com/].

## Requirements

- Python 3.8.13
- Virtual environment (recommended)
- All necessary modules are listed in the `requirements.txt` file.

## Setup and Installation

- Clone the repository: https://github.com/aavasstha/myflicks/tree/main
- Create a virtual environment with python 3.8 installed
- install the dependencies. (pip install -r requirements.txt)
- run the flask app. (flask run)
